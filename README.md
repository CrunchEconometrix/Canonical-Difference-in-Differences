# Canonical-Difference-in-Differences
Replication codes in R and Stata for Canonical Difference-in-Differences (DiD) using the Card & Krueger (1994) dataset.

## 📂 What’s Inside
- minwage_excel.xlsx — Card & Krueger (1994) dataset
- Part2_EDA_*.do / *.R — EDA & Descriptive Evidence (Video Part 2)
- Part3_Regression_*.do / *.R — Canonical DiD Regression & Diagnostics (Video Part 3)
- Part4_Sensitivity_*.do / *.R — Sensitivity Checks & Diagnostics (Video Part 4)
